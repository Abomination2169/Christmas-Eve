# Audio files required for a complete private QMOD build

The public Christmas Eve source snapshot deliberately does **not** include audio recordings. The private Build #131 used the following four Ogg Vorbis files, which the QMOD packaging script expects in this directory:

- `we_wish_you_a_merry_christmas.ogg` — HD-Studio / Pixabay
- `dance_of_the_sugar_plum_fairy.ogg` — Kevin MacLeod / CC BY 4.0
- `M668_Christmas_Lights_5m22_click_removed.ogg` — project owner's 2024 musical-lights recording
- `christmas-eve-aurora-jingle.ogg` — DRAGON-STUDIO / Pixabay

See [`../MUSIC_LICENSES.md`](../MUSIC_LICENSES.md) for full attribution, source links, and rights limitations. No permission to extract or redistribute these audio files is implied by access to the source code. Do not add or distribute them publicly without the necessary rights.
